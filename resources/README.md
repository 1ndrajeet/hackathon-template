# Hackathon Resources

This directory is dedicated to hackathon assets and reference material that are **not** application source code.

## Subdirectories

- **`docs/`**: Problem statements, challenge PDFs, design specifications, judging criteria, and pitch guidelines.
- **`datasets/`**: Sample datasets, CSV files, JSON fixtures, and mock payloads used during hacking.
- **`references/`**: Research notes, architecture diagrams, third-party API documentation links, and cheatsheets.

## Guidelines

- **No Application Code:** Keep all frontend and backend implementation code in `web/` and `server/` respectively.
- **Data Size & Security:** Avoid committing large files (>50MB), sensitive API credentials, or private customer data. Use `.gitignore` for local scratch data.
